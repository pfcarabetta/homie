If you're shopping for a house, you might be juggling 2–4 inspection reports at once. "1234 Main St", "5678 Oak Ave", "9876 Pine Rd" all blur together fast. Give each report a friendly nickname so you can spot it at a glance.

## How

In the **My Reports** tab, hover over any report card. You'll see a small pencil icon between the card and the trash button. Click it to open the rename dialog:

- Type a nickname ("Dream home", "Backup option", "The fixer-upper")
- Or leave it blank to use the property address

The 80-character limit keeps things readable. The actual property address always stays visible as the subtitle on the card, so you don't lose context.

## Where the nickname appears

Once you set it:
- **My Reports list** — title becomes the nickname, address moves to subtitle
- **Report detail view** — same treatment, with a pencil icon next to the title to rename inline
- **Property dropdowns** in Items / Bookings / Negotiations tabs — currently still show the address (we're rolling out nickname support across these next)
- **Repair request PDF** — uses the actual property address (not the nickname) since the PDF is for your agent / the seller

## Clearing the nickname

In the rename dialog, click **"Use property address"** — it instantly clears the nickname and the report falls back to the address title.
